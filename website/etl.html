Task 1: Patient Extraction and Loading

Patient data was extracted from the OpenEMR FHIR server using REST API calls. A specific patient (David Abshire) was retrieved using query parameters such as name and gender.

Patient attributes including name, gender, date of birth, and address were extracted. Associated clinical conditions were retrieved from the FHIR Condition resource.

COPD (SNOMED CT: 13645005) was selected as the primary condition.

  • Tracheobronchial disorder
  • Chronic disease of respiratory system

The patient record was created in the Primary Care EHR FHIR server.

Task 2: Condition (SNOMED)

Child SNOMED concepts for COPD were retrieved and added.

Task 3: Observation

Blood pressure data was retrieved and stored in the target system.

Task 4: Procedure

Chest X-ray procedure created using SNOMED CT.

Task 5: HL7 Message

HL7 v2 message generated using hl7apy and exported.
