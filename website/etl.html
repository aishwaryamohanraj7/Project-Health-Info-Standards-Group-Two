Task 1: Extraction & Patient Task 2: Condition (SNOMED) Task 3: Observation Task 4: Procedure Task 5: HL7 Message

Task 1: Patient Extraction and Loading

Patient data was extracted from the OpenEMR FHIR server using REST API calls. A specific patient (David Abshire) was retrieved using query parameters.

Patient attributes including name, gender, date of birth, and address were extracted. Associated clinical conditions were retrieved from the FHIR Condition resource.

COPD (SNOMED CT: 13645005) was selected as the primary condition.

  • Tracheobronchial disorder
  • Chronic respiratory disease

The patient record was created in the Primary Care EHR FHIR server.

Task 2: Condition Transformation

Child concept codes for COPD were retrieved and mapped using SNOMED CT hierarchy.

These child conditions were added to the patient record for detailed clinical representation.

Task 3: Observation Creation

Blood pressure observations were retrieved from OpenEMR for the same patient.

A new observation resource was created in the target FHIR server.

Task 4: Procedure Creation

A procedure resource (Chest X-ray) was created using SNOMED CT coding.

  • Procedure: Chest X-ray
  • Status: Completed
  • Follow-up included

Task 5: HL7 Message Generation

Patient data was converted into HL7 v2 ADT message format using hl7apy.

The HL7 message was exported as a .txt file for interoperability with legacy systems.
