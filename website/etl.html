📥 Extract Phase

We extracted patient data from OpenEMR using FHIR APIs. This step involved sending authenticated API requests and retrieving structured JSON data. 

response = requests.get(f"{BASE_URL}/Patient", headers=headers)
data = response.json()

print(data['entry'][0]['resource'])

This phase ensures raw healthcare data is collected for processing.

⚙️ Transform Phase

The extracted data was cleaned and standardized using SNOMED CT codes. We mapped conditions and built parent-child relationships. 

condition = {
 "code": "COPD",
 "system": "SNOMED CT",
 "children": ["chronic bronchitis", "emphysema"]
}

Transformation ensures consistent and meaningful clinical data.

📤 Load Phase

The transformed data was loaded into a target EHR system using API POST requests. 

response = requests.post(url, json=condition)
print(response.status_code)

This step enables interoperability between systems.

Task 1: Patient Extraction

Retrieved patient data using FHIR Patient resource. Extracted patient ID and demographic information. 

patient_id = data['entry'][0]['resource']['id']
name = data['entry'][0]['resource']['name'][0]['given'][0]

Output: Patient successfully identified.

Task 2: Condition Mapping

Mapped COPD condition using SNOMED CT and explored its child concepts. 

parent = "COPD"
children = ["chronic bronchitis", "emphysema"]

Output: Condition hierarchy established.

Task 3: Observation

Recorded blood pressure using FHIR Observation resource. 

bp = {"systolic":120,"diastolic":80}

Output: Patient vitals successfully added.

Task 4: Procedure

Recorded a chest X-ray procedure using FHIR Procedure resource. 

procedure = {"name":"Chest X-ray","status":"completed"}

Output: Procedure stored successfully.
