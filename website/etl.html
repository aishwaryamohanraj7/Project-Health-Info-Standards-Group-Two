Task 1: Patient Extraction and Loading

In this step, patient data was extracted from the OpenEMR FHIR server using REST API calls. A specific patient (David Abshire) was retrieved using query parameters such as name and gender.

The system extracted key patient attributes including name, gender, date of birth, and address. Additionally, all associated clinical conditions were retrieved from the FHIR Condition resource.

Chronic Obstructive Pulmonary Disease (COPD) was selected as the primary condition. The SNOMED CT code 13645005 was used to represent COPD.

  • Tracheobronchial disorder
  • Chronic disease of respiratory system

The patient record was then created in the Primary Care EHR FHIR server.

This step represents both the Extraction and Loading phases of the ETL pipeline.

Task 2: Condition Transformation

Child concepts of COPD were retrieved using SNOMED CT terminology. These concepts provide more detailed classification of the condition.

These codes were added to the patient condition in the target system.

Task 3: Observation (Blood Pressure)

Blood pressure data was extracted from OpenEMR and added as a FHIR Observation resource.

This demonstrates integration of clinical measurements into the ETL pipeline.

Task 4: Procedure Creation

A chest X-ray procedure was created and added to the patient record.

  • Status: Completed
  • SNOMED coding applied
  • Follow-up included
