Task 1: Patient Extraction and Loading

Patient data was extracted from the OpenEMR FHIR server using REST API calls. A specific patient (David Abshire) was retrieved using query parameters such as name and gender.

Patient attributes including name, gender, date of birth, and address were extracted. Additionally, associated clinical conditions were retrieved from the FHIR Condition resource.

Chronic Obstructive Pulmonary Disease (COPD) was selected as the primary condition. The SNOMED CT code 13645005 represents COPD.

  • Tracheobronchial disorder
  • Chronic disease of respiratory system

The patient record was created in the Primary Care EHR FHIR server along with the associated condition.

This step represents both the Extraction and Loading phases of the ETL pipeline.

Task 2: Condition (SNOMED)

Child concepts of COPD were retrieved using SNOMED CT hierarchy. These child conditions were added to the patient record.

This step represents the Transformation phase where clinical terminology is standardized.

Task 3: Observation

Blood pressure observations were retrieved from OpenEMR for the same patient.

The observation data was transformed and added to the target FHIR server.

This ensures accurate patient monitoring data is transferred across systems.

Task 4: Procedure

A procedure resource was created representing a chest X-ray.

  • Procedure: Chest X-ray
  • Status: Completed
  • Follow-up information included

SNOMED CT coding was used to standardize the procedure.

This step extends the Loading phase of the ETL pipeline.

Task 5: HL7 Message

Patient data was converted into HL7 v2 format using the hl7apy library.

The message includes patient name, age, gender, and clinical information.

The HL7 message was exported as a text file for interoperability with legacy systems.

This step ensures compatibility between modern FHIR systems and traditional healthcare systems.
