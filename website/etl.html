📥 Extract Phase

Data is extracted from OpenEMR using FHIR APIs. This involves sending authenticated HTTP requests and retrieving structured JSON data. 

import requests

url = "https://api.openemr.com/fhir/Patient"
headers = {"Authorization": "Bearer ACCESS_TOKEN"}

response = requests.get(url, headers=headers)
data = response.json()

print(data)

This step ensures raw patient data is collected for further processing.

⚙️ Transform Phase

Raw FHIR data is cleaned and standardized using SNOMED CT terminology. Parent-child relationships are used to structure clinical concepts. 

condition = {
    "code": "COPD",
    "system": "SNOMED CT",
    "children": ["chronic bronchitis", "emphysema"]
}

print(condition)

Transformation ensures consistency and prepares data for interoperability.

📤 Load Phase

Transformed data is loaded into a target EHR system using API requests. 

post_url = "https://api.targetehr.com/fhir/Condition"

response = requests.post(post_url, json=condition)
print(response.status_code)

This step ensures processed data is stored and accessible for clinical use.

Task 1: Patient Extraction

Patient data is retrieved from the FHIR API and relevant patient information is extracted. 

patient_id = data['entry'][0]['resource']['id']
print("Patient ID:", patient_id)

Task 2: Condition

SNOMED CT codes are applied to identify conditions such as COPD and its related child concepts. 

parent = "COPD"
children = ["chronic bronchitis", "emphysema"]

print(parent, "->", children)

Task 3: Observation

Observations such as blood pressure are recorded using FHIR Observation resource. 

bp = {
    "systolic": 120,
    "diastolic": 80
}
print(bp)

Task 4: Procedure

Medical procedures like chest X-ray are recorded using Procedure resource. 

procedure = {
    "name": "Chest X-ray",
    "status": "completed"
}
print(procedure)
