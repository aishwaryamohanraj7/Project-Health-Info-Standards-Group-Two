Extract Phase

The extraction phase retrieves raw healthcare data from the OpenEMR system using FHIR APIs. This step is critical because it ensures that all patient-related information is collected in a structured format.

  • Established connection to OpenEMR FHIR server
  • Authenticated API requests using access tokens
  • Fetched Patient resources using HTTP GET requests
  • Handled JSON response parsing
  • Filtered relevant patient data using query parameters
  • Validated API response status and structure

Code


import requests

url = f"{BASE_URL}/Patient"
headers = {"Authorization": f"Bearer {ACCESS_TOKEN}"}

response = requests.get(url, headers=headers)

if response.status_code == 200:
    data = response.json()
    print(data['entry'][0]['resource'])
else:
    print("Error:", response.status_code)

Outcome: Successfully retrieved structured patient data for further processing.

End-to-end ETL pipeline: Extraction → Transformation → Loading with FHIR & HL7 interoperability

Transform Phase

In this phase, raw FHIR data is cleaned, standardized, and enriched using SNOMED CT terminology. This ensures interoperability and semantic consistency.

  • Removed incomplete or inconsistent data
  • Mapped clinical conditions using SNOMED CT codes
  • Created parent-child relationships for diseases
  • Structured JSON into standardized format
  • Prepared data for downstream systems

condition = {
    "code": "COPD",
    "system": "SNOMED CT",
    "children": [
        "chronic bronchitis",
        "emphysema"
    ]
}

Outcome: Data transformed into clinically meaningful and standardized format.

Load Phase

The load phase inserts transformed data into the target EHR system, ensuring accessibility and interoperability.

  • Used HTTP POST requests to send data
  • Ensured compliance with FHIR resource structure
  • Validated response from target system
  • Handled success and error cases
  • Stored processed data for clinical use

response = requests.post(target_url, json=condition)

if response.status_code == 201:
    print("Data loaded successfully")
else:
    print("Error:", response.status_code)

Outcome: Data successfully stored in target system.
