Task 1: Patient Extraction and Loading

Patient data was extracted from the OpenEMR FHIR server using REST API calls. A specific patient (David Abshire) was retrieved using query parameters.

Patient attributes such as name, gender, date of birth, and address were extracted. Associated clinical conditions were retrieved from the FHIR Condition resource.

COPD (SNOMED CT: 13645005) was selected as the primary condition.

  • Tracheobronchial disorder
  • Chronic respiratory disease

The patient was created in the Primary Care EHR FHIR server.

Task 2: Condition (SNOMED)

Child concepts of COPD were retrieved using SNOMED CT hierarchy. These were added as conditions for the patient.

Task 3: Observation

Blood pressure observations were retrieved from OpenEMR and added to the target system.

Task 4: Procedure

A chest X-ray procedure was created using SNOMED CT coding.

  • Procedure: Chest X-ray
  • Status: Completed
  • Follow-up recorded

Task 5: HL7 Message

Patient data was converted into HL7 v2 format using hl7apy. The message includes patient demographics and clinical data.
