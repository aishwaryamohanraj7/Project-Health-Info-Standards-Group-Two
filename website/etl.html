📥 Extract ⚙️ Transform 📤 Load
Task 1: Extraction & Patient Task 2: Condition Task 3: Observation Task 4: Procedure Task 5: HL7 Message

Extract Phase

Data is retrieved from OpenEMR FHIR API including patients, conditions, and observations.

Transform Phase

Data is standardized using SNOMED CT mappings and cleaned for interoperability.

Load Phase

Processed data is sent to the Primary Care EHR system and converted into HL7 format.

Patient data was extracted from OpenEMR FHIR server using REST APIs.

Patient details like name, gender, DOB, and address were retrieved.

COPD (SNOMED CT: 13645005) selected as primary condition.
