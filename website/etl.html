📥 Extract Phase

The extraction phase is responsible for retrieving raw patient data from the OpenEMR system using FHIR APIs.

  • Connected to OpenEMR FHIR server
  • Used secure authentication with access tokens
  • Fetched Patient resources using HTTP GET requests
  • Retrieved structured JSON responses
  • Filtered relevant patient records using search parameters
response = requests.get(f"{BASE_URL}/Patient", headers=headers)
data = response.json()

Outcome: Successfully extracted structured patient data for processing.

⚙️ Transform Phase

The transformation phase converts raw data into standardized clinical format using SNOMED CT.

  • Cleaned inconsistent and missing data
  • Mapped conditions using SNOMED CT codes
  • Established parent-child relationships
  • Converted raw JSON into structured format
  • Prepared data for interoperability
condition = {
 "code": "COPD",
 "system": "SNOMED CT",
 "children": ["chronic bronchitis", "emphysema"]
}

Outcome: Data transformed into consistent and meaningful clinical representation.

📤 Load Phase

The load phase sends transformed data into the target EHR system.

  • Used POST requests to send data
  • Ensured correct FHIR resource format
  • Validated response status
  • Stored processed data in system
  • Enabled interoperability between systems
response = requests.post(url, json=condition)
print(response.status_code)

Outcome: Data successfully stored in target system.
