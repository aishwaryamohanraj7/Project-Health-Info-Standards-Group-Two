FHIR ETL Pipeline: Bridging Clinical Data Systems

This project implements a clinical data ETL (Extract, Transform, Load) pipeline that connects two FHIR-compliant healthcare systems — an OpenEMR source server and a Primary Care EHR target server.

The pipeline retrieves patient and clinical data, enriches it using SNOMED CT terminology, and delivers structured FHIR R4 resources to a destination system.

Additionally, interoperability is achieved by converting FHIR data into HL7 v2 ADT messages for integration with legacy healthcare systems.

🎯 Purpose of the ETL Pipeline

Healthcare systems often operate in silos, making data exchange difficult. This ETL pipeline addresses that challenge by automating:

  • Extraction of patient data from OpenEMR
  • Transformation using standardized clinical terminology (SNOMED CT)
  • Loading data into a Primary Care EHR system
  • Conversion to HL7 v2 for interoperability

The result is improved data consistency, reduced manual effort, and enhanced clinical interoperability.

⚙️ Technologies Used

  • Python – ETL pipeline implementation
  • FHIR API – Healthcare data exchange
  • SNOMED CT – Clinical terminology standardization
  • HL7 v2 – Legacy system interoperability
  • hl7apy – HL7 message generation
  • GitHub Pages – Website hosting
