FHIR ETL Pipeline: Bridging Clinical Data Systems

This project builds an ETL pipeline that extracts patient data from OpenEMR, transforms it using SNOMED CT, and loads it into a Primary Care EHR, with HL7 v2 conversion for interoperability.
