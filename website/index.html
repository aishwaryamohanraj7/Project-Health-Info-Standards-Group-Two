FHIR ETL Pipeline: Bridging Clinical Data Systems

This project implements a clinical data ETL (Extract, Transform, Load) pipeline that connects two FHIR-compliant healthcare systems — an OpenEMR source server and a Primary Care EHR target server. The pipeline retrieves real patient and condition data, enriches it using the SNOMED CT clinical terminology hierarchy, and delivers structured FHIR R4 resources to a destination system. A final interoperability layer converts FHIR data into an HL7 v2 ADT message, enabling communication with legacy clinical systems.

🎯 Purpose of the ETL Pipeline

Healthcare organizations routinely operate multiple electronic health record systems that do not communicate natively. This pipeline solves that problem by automating the extraction of patient demographics and clinical conditions, applying standardized clinical terminology transformations, and loading the enriched data into a second EHR system — all without manual data entry. The result is faster, more accurate patient data migration and a foundation for true clinical interoperability.
