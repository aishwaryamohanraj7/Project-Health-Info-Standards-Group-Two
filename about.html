Project Overview

This project demonstrates a healthcare ETL pipeline using FHIR APIs. Data is extracted from OpenEMR, transformed using SNOMED CT, and loaded into a Primary Care EHR system. The pipeline also supports HL7 v2 conversion for legacy system interoperability.

Objective

  • Enable healthcare data interoperability
  • Standardize clinical data using SNOMED CT
  • Build an end-to-end ETL pipeline
  • Support legacy systems using HL7 v2

ETL Workflow

  • Extract: Retrieve patient data using FHIR API
  • Transform: Clean data and map SNOMED codes
  • Load: Send processed data to target EHR
